# Set up docs/ as memex KB with GitHub Pages publishing

Use mx (memex) to turn docs/ into a project-specific knowledge base, then use mx publish to generate GitHub Pages-friendly static files.

Goals:
1. Initialize docs/ as a memex KB (or create a dedicated kb/ directory)
2. Configure mx publish to output GH Pages compatible files
3. Document the workflow for updating docs

This enables searchable documentation hosted on GitHub Pages. User will configure GH Pages to point to the published directory.
